# 朋友圈发布通知

入口：WcS 设置 → 功能 → 朋友圈 → 朋友圈发布通知。

指定好友发布新朋友圈时提醒。开启后点击功能，选择提醒好友、提醒方式和提醒模板。未选择任何好友时不会提醒。

只提醒**开启功能之后**发布的朋友圈：开启那一刻会记一个时间基准，之前的历史内容一律跳过，关闭功能会清掉基准与已提醒记录。同一条朋友圈只提醒一次，记录上限 1000 条，超出后丢弃最旧的。

提醒方式可单独开关：系统通知（通知渠道「朋友圈发布通知」，可展开看正文）与 Toast（在微信界面短暂显示）。两者都关时功能不做任何处理。点通知的落点另有两个开关：「点击通知打开朋友圈」进朋友圈动态流，「点击通知打开该好友朋友圈」进发布者的朋友圈。两者互斥，开一个会自动关掉另一个；都关时只把微信带到前台。跳转时底下都垫一个微信首页，返回键能退回首页。

模板留空即使用默认文案，可填变量 `%sender%`（发布者显示名）、`%wxid%`、`%type%`（内容类型，取自 WcS 的朋友圈类型表）、`%content%`（正文，最多 500 字）、`%snsid%`。填了 `%content%` 就等于把朋友圈正文写进通知，锁屏上是否可见取决于系统设置（本功能把通知标为私密，内容在锁屏受系统策略约束）。

功能只观察微信自己写入朋友圈数据库的时机，不额外请求网络、不需要朋友圈权限，也不会主动刷新朋友圈。因此提醒的及时性取决于微信何时把该好友的新内容写进本地——通常是你刷新或刷到朋友圈时。
