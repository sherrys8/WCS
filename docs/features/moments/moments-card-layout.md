# 朋友圈卡片布局

> 把每一条朋友圈画成独立的圆角卡片

## 类别

朋友圈、美化

## 类型

可开关（点击功能行可打开设置）

## 描述

给朋友圈时间线的每一条动态涂上一层独立圆角卡片背景，并隐藏行间的通栏分隔线。观感对齐主页的「美化对话列表」，画法也相同（圆角矩形 + 内缩 + 按波纹）：

- 圆角 20dp
- 左右内缩 10dp
- 上下内缩 4dp（相邻两行各缩一次，所以卡片之间的可见间距是 8dp）
- 底色浅色 `#F7FAF9`、深色 `#252827`
- 描边 1dp 可在设置里开关（默认开）

内容会随卡片一起右移 10dp。这一步是必须的：真机实测头像左边缘在 12.6dp、正文顶部距行顶只有 5.4dp，而 20dp 的圆弧在头像顶部那一行已经横向切进约 12.6dp，不给内容让位的话头像左上角会露在弧线外面。

只作用在动态条目上。顶部的封面块是列表里的另一种条目，广告条也一样按条目类型排除，都不会被卡片化。

## 使用方法

在模块设置中启用，点击功能行可以选择是否给卡片描边。开关切换后需要重新进入朋友圈才会作用到新的条目上；描边开关当场生效。
