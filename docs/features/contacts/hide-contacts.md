# 隐藏联系人

入口：WcS 设置 → 功能 → 联系人与群组 → 隐藏联系人。

按隐藏列表控制联系人在会话、通讯录、搜索、朋友圈及通知/通话相关界面的显示。开启后点击「配置隐藏列表」选择联系人。

## 隐藏时机

隐藏由「离开微信」或「息屏」触发，两个开关默认关闭、彼此独立：

- **离开微信时隐藏**：切到其它应用或按 HOME 回桌面时摘掉隐藏联系人，最近任务卡片上看不到。判据是宿主 Activity 的 started 计数，微信内部页面跳转不会误触发。
- **息屏时隐藏**：息屏即隐藏。

触发后的隐藏是持久的：回到微信、解锁都不会自动恢复显示，只有下面的手动恢复手段才有效。

## 手动恢复

- 长按或三击主页标题，恢复显示；
- 在聊天输入栏发送 `#show`；再次发送 `#hide` 则收回显示；
- 定时显示/隐藏；
- 直接关闭本功能。

再次离开微信或息屏时，上一次的手动显示会被清掉、隐藏重新生效；这些操作都不修改已保存的隐藏列表。

锁屏和摇动设备会关闭相关隐藏聊天页面。功能用于本机显示管理，不删除联系人或聊天记录，也不保证所有微信页面和外部通知历史都没有痕迹。

## 音视频通话

「自动拒绝音视频通话」默认关闭：关闭时隐藏来电界面，对方可能一直响铃到超时；开启后向对方发送拒接。按需要选择，避免把隐藏来电视为没有收到来电。
