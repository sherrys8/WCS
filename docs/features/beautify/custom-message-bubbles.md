# 自定义消息气泡

入口：WcS 设置 → 功能 → 界面美化 / 聊天 → 自定义消息气泡。

开启后点击功能，分别设置自己与对方消息的文字色、背景色以及 `.9.png` 气泡图片；亮色和暗色模式可以独立配置。

通过设置中的「导入/更换」选择九宫格 PNG，模块会验证格式与尺寸，也可以删除已导入的图片。不要把普通大尺寸照片作为气泡文件导入。

颜色和图片只影响本地聊天显示，实际覆盖取决于对应消息类型的绘制方式。

## 按压缩放反馈

设置弹窗底部的「按压缩放反馈」开关（默认关闭）给普通气泡补上按压响应：按下时整块气泡轻微缩小、松开回弹，各 100ms。幅度按气泡高度动态计算 —— 600px 以内的小气泡缩到约 0.9525，越高的气泡越轻微，超长消息几乎不动，避免大块内容整体缩放产生眩晕感。

- 只作用于普通气泡（文本、链接、群公告、引用、语音、VOIP），红包与转账卡片不参与。
- 微信自己已经带按压动画的气泡不会被接管。
- 缩放发生在绘制层，动画期间文字会有轻微模糊，属正常现象。
- 关闭开关后，已经挂上动画的气泡要等微信重建该条目（重进聊天或重启微信）才恢复原状。
