# 虚拟定位

入口：WcS 设置 → 功能 → 系统与隐私 → 虚拟定位。

开启后向微信的相关定位调用提供选定坐标。点击功能可选择「微信位置选择器」或「OpenStreetMap 选择器」，选点并确认后保存。

这不是修改手机的系统定位，也不会改变其他应用的位置。选择器需要可用的前台页面；地图、网络或位置结果读取失败时会提示原因。

## 随机瞬移

点功能行打开设置弹窗，分两组：「定位点」显示当前中心坐标，点击仍走原来的选点流程（微信选择位置页或 OpenStreetMap 选点）；同一组里的「清除已选位置」一键把中心坐标恢复成默认值（31.224361，121.469170），已经是默认值时该行置灰。「随机瞬移」开关**默认关闭**。

开启后，微信每次取定位都在以中心点为圆心、瞬移半径为范围的圆内随机取一个点，并给出 10～50 米的随机定位精度；关闭即回到固定坐标，就是原来的虚拟定位。

- 同一次定位的经纬度取自同一个随机点，不会拼出一个从未取过的坐标；「最短驻留」是同一个定位对象被长期复用时的换点间隔。
- 只改坐标，不改微信反查出来的地址文字：直接显示地址文字的场景（如朋友圈定位）会与坐标不一致；「发送位置」「位置共享」把坐标写进消息、由对方地图渲染，不受影响。
- 半径 ÷ 驻留时间就是名义速度，跨度大而间隔短时会非常不自然。
- 仍然只在微信主进程生效，小程序内的定位不受影响。
