# QQ 点歌

入口：WcS 设置 → 功能 → 娱乐 → QQ点歌。

在聊天里发送「点歌 歌名」，功能会去 QQ 音乐搜索，把结果以**音乐卡片**和/或**歌曲语音**发回当前会话。默认关闭，默认触发词为「点歌」。

只有**你自己**发的消息会被无条件响应；别人发的消息只在所在会话被列入「允许点歌的会话」时才会响应，白名单为空时不会替任何人点歌。为避免重放历史消息，只处理入库时间在过去 30 秒内的文本消息，系统消息与非文本消息一律忽略。

可选行为：

- **音乐卡片**：微信原生的音乐分享卡片，点开跳转 QQ 音乐网页版，带歌词滚动字幕。
- **歌曲语音**：下载歌曲后转成微信语音消息发送，流量与耗时明显更高（一首歌几十 MB 上限 128 MB），默认关闭。下载与转码的中间文件放在 `Download/WcS/MusicOrder`（与短视频解析的 `Download/WcS/ParseVideo` 同级）；已经交给微信的语音文件不会立刻删（上传是异步的），超过 30 分钟的残留文件会在下次点歌时清掉。
- **固定歌手名**：卡片上的歌手统一显示为指定值；开启后还支持「点歌 歌名&歌手」只对这一首临时指定。
- **用点歌人的昵称作为歌手**：优先群昵称，其次备注名、昵称。与「固定歌手名」互斥。
- **用点歌人的头像作为封面**：取不到头像时退回歌曲封面。

失败会以引用回复的形式回话（引用不可用时退化为普通文本）：没搜到、版权或数字专辑限制、卡片/语音发送失败。

两点与来源实现（Hchat 的 QQ 点歌）的差异：命令文本会**照常出现在聊天里**——WcS 没有「吞掉这次发送」的切入点，只监听消息入库；会话内开关「开启点歌 / 关闭点歌」也没有移植，白名单统一在设置界面维护。

搜索与播放地址来自 QQ 音乐的公开 web 接口，无需登录，但也随时可能变动；接口失效时功能只会回「获取失败」，日志里能看到具体请求失败原因。第三方内容受版权策略限制，部分歌曲取不到可播放地址属正常现象。
